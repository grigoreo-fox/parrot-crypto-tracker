# ADR 0002: Драйвер SQLite для Node.js 18

- Статус: принято; отклонение от списка библиотек требует согласования с проверяющими
- Дата: 2026-11-07

## Контекст

Задание требует Node.js 18+, SQLite и работу с БД через raw SQL без ORM. При этом разрешены только перечисленные библиотеки и стандартные возможности Node.js; если ограничения несовместимы, задание предлагает обосновать своё решение.

Node.js 18 не включает встроенный модуль `node:sqlite`: он появился только в Node.js 22.5.0 ([документация Node.js](https://nodejs.org/api/sqlite.html)). Повышение минимальной версии до Node.js 22.5.0 исключило бы Node.js 18 и не соответствует принятой совместимости с минимумом задания. Само название SQLite в стеке не предоставляет Node.js 18 интерфейс к базе.

## Варианты

1. **`better-sqlite3`.** Сторонний поддерживаемый драйвер с параметризованными SQL-запросами и транзакциями, без ORM. Требует дополнительной зависимости и использует синхронный API.
2. **Другой драйвер SQLite.** Тоже требует дополнительной зависимости; например, репозиторий распространённого пакета [`sqlite3`](https://github.com/TryGhost/node-sqlite3) помечен как неподдерживаемый. Утверждать, что `better-sqlite3` — единственный поддерживаемый драйвер, без обзора всех альтернатив нельзя.
3. **Встроенный `node:sqlite`.** Исключает сторонний драйвер, но недоступен в Node.js 18 и требует повышения минимальной версии.
4. **Собственный драйвер или интеграция с SQLite.** Потребует самостоятельно решать вопросы совместимости, ошибок и безопасности; сложность несоразмерна тестовому заданию. Вызов внешней утилиты SQLite также вводит внешнюю зависимость и усложняет работу с параметрами и транзакциями.

## Решение

Использовать `better-sqlite3` как драйвер для SQLite; выполнять параметризованные raw SQL-запросы и транзакции, не использовать ORM. Это обоснованное отклонение от буквального списка библиотек, а не утверждение, что задание его уже разрешило. Указать зависимость при сдаче и при необходимости согласовать с проверяющими.

## Последствия

- Сохраняется выбранная цель совместимости с Node.js 18, но установленная версия драйвера и полный набор инструментов должны быть проверены на Node.js 18; прохождение тестов на другой версии этого не подтверждает.
- Синхронные операции SQLite блокируют event loop; длительные запросы могут задерживать HTTP-запросы и фоновые задачи. Для текущего учебного сервиса это принимаемый компромисс, при росте нагрузки решение следует пересмотреть.
- Нативная зависимость требует совместимого бинарного пакета либо условий для её сборки в целевом окружении.
- Если проверяющие не примут дополнительную библиотеку, необходимо согласовать альтернативу и её последствия для минимальной версии Node.js или архитектуры.
